Ovaj projekat je web aplikacija napravljena sa HTML-om,CSS-om i JS-om.
Napravljena je unutar JS Reacta(koristi Vite ne yarn)
Liči na prodavnicu bjele tehnike i ima word search funkciju.
Pokretanje:

1. Klonirajte repozitorij:
   ```bash
   git clone [https://github.com/Time585/praksa-js-rect.git](https://github.com/Time585/praksa-js-rect.git)
Uđite u mapu repozitorija, a zatim u folder projekta:

Bash
cd praksa-js-rect/DAY6
Instalirajte potrebne pakete:

Bash
npm install
Pokrenite aplikaciju:

Bash
npm start
